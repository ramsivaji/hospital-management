# T-016 — Landing Page

Track: **Frontend** · Depends on: T-014 · Status: ⬜ Not started

---

## Goal

Build the public-facing landing page with scroll-driven animations and a sticky storytelling section.

## Acceptance Criteria

- [ ] Hero section with headline, sub-copy, and CTA button
- [ ] Scroll-driven staggered reveals for feature sections (using `spring.gentle`)
- [ ] Sticky storytelling section (content changes as user scrolls through it)
- [ ] "How it works" section with animated step cards
- [ ] Specialty cards linking to the doctor discovery page
- [ ] Footer with links
- [ ] Profiler shows **60 fps** during scroll on a mid-range device
- [ ] Reduced-motion fallback: instant appearance, no scroll effects
- [ ] Fully responsive (mobile, tablet, desktop)
